# ML-Sonar_Vs_Rock_Prediction

Rock vs Mine Prediction
Overview

This project predicts whether a sonar signal represents a Rock or a Mine using a machine learning classification model.

Files

Copy_of_Rock_vs_Mine_Prediction.ipynb – Model training and testing

Copy of sonar data.csv – Sonar dataset

Approach

Type: Supervised Learning

Problem: Binary Classification

Algorithm: Logistic Regression

Libraries: NumPy, Pandas, Scikit-learn

How to Run

Open the notebook in Jupyter or Google Colab

Upload the CSV file

Run all cells

Output

Predicts Rock or Mine

Displays model accuracy
